# Security Policy

We take the security of PagePulse seriously. If you believe you have found a security vulnerability, please report it to us responsibly using the guidelines below.

---

## Supported Versions

Only the latest release version of PagePulse is supported with security updates.

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |
| < 1.0   | No        |

---

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, report vulnerabilities via email. We will acknowledge receipt of your report within 48 hours and provide a timeline for addressing the issue.

### What to Include in Your Report:
- A description of the vulnerability and its potential impact.
- Detailed step-by-step instructions to reproduce the issue.
- Any proof-of-concept scripts or payload details.
- System details (OS, Python version, Node.js version).

---

## Responsible Disclosure

To protect the community, we request that you:
- Give us a reasonable amount of time to resolve the issue before disclosing it publicly.
- Do not exploit the vulnerability for malicious purposes (e.g., harvesting user data, causing service degradation).
- Work with us to clarify details or verify the fix where helpful.
